# cell_no_ai

独立 skill，不调用或修改 cell_su7 等绘图流程。

## 每次使用先说明功能

每次用户发起本 skill 的新请求，执行操作前先用简短中文说明两项功能和费用前提；同一任务的轮询、下载或进度更新无需重复。用户已明确选择功能时，说明后直接进入对应流程，不要求重新选择。

建议开场：“cell_no_ai 有两项功能：① 打开官方水印验证页，供你自行上传检测；② 通过 API 去 AI 水印并下载结果。去水印必须先查询并显示实时可用余额，本次消耗 1 额度；余额查询失败或不足 1 额度不提交。”

如余额接口尚未接通，必须紧接说明当前无法提交去水印任务，不能把功能介绍说成已具备可用的余额查询能力。

## 检测

直接打开并显示 https://openai.com/zh-Hans-CN/research/verify/ 给用户自行粘贴或上传图片。已有该页则复用。无需读取图片、查询元数据、代上传、调用检测 API、等待或读取检测结果。打开受阻只提供链接。用户主动要求解读其提供的结果时才解读。

## 强制余额前置检查

每次新建付费任务前，必须先用同一 API Key 成功查询实时可用余额并显示。可用余额必须明确且至少为 1 个额度。余额为 0、不足 1、查询失败、结果缺失/无效或接口未知时，一律不得调用 POST /api/watermark-jobs，不得上传图片或预留额度。

用户说“提交”“继续”只表示处理意图，不代替余额检查；不能以“余额暂不可用，但用户已确认 1 额度”为由跳过。不得使用旧余额、估算余额、累计余额代替可用余额，也不得用提交接口是否返回 402 来试探余额。每张新图重新查询；有效扣费授权不能豁免余额前置检查。

失败时明确告知：“实时余额查询未成功，尚未提交图片。” 若余额为 0 则说明额度不足。只有取得可验证的实时余额并显示后才继续。已经提交且预留额度的任务可以继续查询和领取原结果，不重新提交、不新建任务；此例外仅用于完成已有任务，不允许绕过新任务的前置检查。

## 去 AI 水印：仅接口

读取 [references/workflow.md](references/workflow.md) 和 [references/api.md](references/api.md)，直接使用 HTTPS API，不打开小描网页、不操作浏览器上传。文档网址只用于核实接口，不是用户操作步骤。

1. 保留原图。含文字时建议去字副本，但不能擅自删除用户要保留的文字；已同意去字则先去字并核对图形和坐标，未同意则保留文字或询问偏好。
2. 通过已正式文档化的只读 API 获取实时可用余额。显示 `当前可用余额：N；本次去 AI 水印消耗 1 个额度（提交预留，首次领取正式扣除）。` 不使用历史余额、不猜余额接口、不上传探测余额。调用 `GET https://xiaomiao-ai.com/api/balance`，使用同一 Bearer API Key。仅 HTTP 200、`ok=true` 且 `available_credits` 为有效非负数时接受余额；至少 1 才能继续。该数值已扣除预留额度，不再重复扣减。不缓存余额。详见 references/api.md。
3. 使用现有安全存储的小描 API Key。Windows 可读取用户已有 DPAPI 密文，macOS 可复用已配置 Keychain；只在进程内解密，通过 Authorization 请求头发送。不要把明文写入日志、命令参数、URL 或文件，也不重新创建无关密钥。没有配置时请求用户提供/配置凭据。
4. 只有余额前置检查已通过，且当前图片已有明确的一额度处理授权时才不重复询问；否则先完成余额查询，再显示余额与费用并询问是否提交。仅修改 skill 不消耗额度。
5. 调用 POST /api/watermark-jobs，multipart 字段 image，PNG/JPG。提交只执行一次，立即保存 job_id、expires_at 和输入文件路径，不记录凭据。网络超时且提交状态不明时不能盲目重发。
6. 轮询原 job_id 的状态接口，completed 后及时领取结果。任务和文件自提交起保留 15 分钟。失败/取消/过期停止；不自动新建任务。取消仅在用户要求或明确授权时执行。
7. 使用同一鉴权下载图片，先保存临时文件并验证真实图片格式，再按实际格式另存新文件，不覆盖原图。记录 X-Xiaomiao-Charged（1 首次扣费，0 重复领取）及服务实际返回的余额，缺失写暂不可用，不推算。
8. 检查返回图可读、尺寸和构图是否变化。若需要水印检测，只打开官方验证页交给用户自行操作。不能把下载成功说成保证所有隐藏水印已去除。

## 当前限制

2026-09-06 官方 /docs 已提供只读余额接口 /api/balance。查询本身不扣额度；services 中 can_submit 仅表示余额和权限条件，不代表处理人员在线。余额接口失败或字段缺失时停止，不构造余额、不上传试探。

C2PA/SynthID 背景参见 [references/sources.md](references/sources.md)。OpenAI 检测页明确支持这两种信号；未检测到不证明非 AI 或没有其他水印。
